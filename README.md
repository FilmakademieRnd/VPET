# VPET - Virtual Production Editing Tools
![VPET](.doc/img/main/vpet_logo.jpg)

VPET is a collaborative tool that allows realtime scene editing via an intuitive interface.<br>
It takes a holistic approach on light, asset and animation editing, for virtual production environments.<br>
Its development is open-source, with growing support for diverse film and VFX pipelines.

## VPET Client App

Download the free VPET app for your devices:

* [iOS - Apple App Store](https://apps.apple.com/de/app/vpet/id1374394388)
* [Android - APK file](https://github.com/FilmakademieRnd/VPET/releases/download/VPET_Android/vpet.apk)
* [Windows - ZIP File](https://github.com/FilmakademieRnd/VPET/releases/download/VPET/VPET_Win_x64.zip)

Note: The client app was developed with Unity Engine and can be custom built for specific needs.  
The Unity project can be found under the *VPET_Unity* directory.
